# Отключение пайплайнов при синхронизации с upstream

Этот набор скриптов помогает синхронизировать форк freqtrade с upstream репозиторием без запуска CI/CD пайплайнов.

## Проблема

При синхронизации форка с upstream репозиторием автоматически запускаются все пайплайны:
- CI тесты (занимают много времени и ресурсов)
- Docker сборка и публикация
- Документация
- Очистка пакетов

Это нежелательно, так как:
- Тратит ресурсы GitHub Actions
- Может привести к конфликтам с Docker образами
- Замедляет процесс синхронизации

## Решения

### Вариант 1: Временное отключение пайплайнов (Рекомендуется)

```bash
./sync-disable-pipelines.sh
```

**Как работает:**
1. Временно переименовывает все `.yml` файлы в `.yml.disabled`
2. Синхронизирует с upstream
3. Возвращает пайплайны обратно

**Плюсы:**
- Гарантированно отключает все пайплайны
- Простота и надежность
- Не требует модификации пайплайнов

**Минусы:**
- Создает дополнительные коммиты

### Вариант 2: Использование специальных коммит-сообщений

```bash
./sync-with-skip-pipelines.sh
```

**Как работает:**
1. Добавляет `[skip ci] [skip actions] [skip pipeline]` в коммит-сообщение
2. Синхронизирует с upstream

**Плюсы:**
- Не создает лишних коммитов
- Стандартный подход GitHub

**Минусы:**
- Требует модификации пайплайнов для поддержки этих тегов

### Вариант 3: Модификация пайплайнов

```bash
./modify-pipelines-for-skip.sh
```

**Как работает:**
1. Добавляет условие пропуска в каждый пайплайн
2. Пайплайны пропускаются при наличии специальных тегов в коммите

**Плюсы:**
- Постоянное решение
- Гибкость в управлении

**Минусы:**
- Требует модификации оригинальных пайплайнов
- Может конфликтовать при обновлениях upstream

## Настройка

### Первоначальная настройка

1. Добавьте upstream remote:
```bash
git remote add upstream https://github.com/freqtrade/freqtrade.git
```

2. Выберите один из вариантов выше

### Автоматическая синхронизация

Можно настроить автоматическую синхронизацию через GitHub Actions или cron:

```bash
# Добавить в crontab для ежедневной синхронизации в 3:00
0 3 * * * cd /path/to/freqtrade && ./sync-disable-pipelines.sh
```

## Рекомендации

1. **Для разовой синхронизации:** используйте `sync-disable-pipelines.sh`
2. **Для регулярной синхронизации:** сначала выполните `modify-pipelines-for-skip.sh`, затем используйте `sync-with-skip-pipelines.sh`
3. **Для продакшена:** рассмотрите использование GitHub Actions с секретами для автоматической синхронизации

## Безопасность

- Все скрипты создают бэкапы перед изменениями
- Проверяют статус git перед выполнением
- Запрашивают подтверждение при наличии незакоммиченных изменений

## Восстановление

Если что-то пошло не так:

```bash
# Восстановить оригинальные пайплайны из бэкапа
cp -r .github/workflows.backup/* .github/workflows/

# Или сбросить изменения
git checkout -- .github/workflows/
```
