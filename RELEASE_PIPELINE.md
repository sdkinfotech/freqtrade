# 🚀 Freqtrade Release Pipeline

Автоматизированный пайплайн для обновления Freqtrade с возможностью ручного управления.

## 📋 Доступные пайплайны

### 1️⃣ **🔄 Scheduled Check for Updates**
- **Запуск:** Ежедневно в 9:00 UTC
- **Функция:** Проверяет новые релизы freqtrade
- **Действие:** Создает GitHub Issue при обнаружении новой версии

### 2️⃣ **🚀 Manual Release Pipeline**
- **Запуск:** Ручной через GitHub Actions
- **Функция:** Полный контроль над процессом обновления

## 🎛️ Ручное управление

### Доступные действия:

#### 🔍 **Check** - Проверка версий
- Проверяет последнюю версию freqtrade
- Сравнивает с текущей версией
- Показывает статус обновления

#### 🐳 **Build** - Сборка образа
- Собирает Docker образ с указанной версией
- Пушит в Docker Hub
- Обновляет файл версии

#### 📦 **Deploy** - Деплой Helm чарта
- Обновляет Helm чарт в репозитории `cd_freqtrade`
- Уведомляет ArgoCD
- Готовит к деплою в Kubernetes

#### 🚀 **Full Release** - Полный релиз
- Выполняет все действия последовательно:
  1. Проверка версии
  2. Сборка образа
  3. Деплой Helm чарта

### Параметры:

- **Version** - Конкретная версия (оставьте пустым для последней)
- **Force** - Принудительное обновление даже если версия уже существует

## 🔧 Настройка

### Secrets в GitHub:
- `DOCKER_USERNAME` - Docker Hub логин
- `DOCKER_PASSWORD` - Docker Hub пароль/токен
- `ARGOCD_WEBHOOK_URL` - URL webhook ArgoCD (опционально)

### Репозитории:
- **Основной:** `sdkinfotech/freqtrade` - исходный код и пайплайны
- **Helm чарты:** `sdkinfotech/cd_freqtrade` - Helm чарты для деплоя

## 📊 Примеры использования

### Проверка новой версии:
1. Перейдите в **Actions** → **🚀 Manual Release Pipeline**
2. Нажмите **Run workflow**
3. Выберите **check** в поле Action
4. Нажмите **Run workflow**

### Полный релиз:
1. Перейдите в **Actions** → **🚀 Manual Release Pipeline**
2. Нажмите **Run workflow**
3. Выберите **full-release** в поле Action
4. Нажмите **Run workflow**

### Принудительное обновление:
1. Выберите **full-release**
2. Укажите конкретную версию в поле **Version**
3. Поставьте галочку **Force**
4. Нажмите **Run workflow**

## 🔄 Автоматический процесс

```
Ежедневная проверка → Новый релиз → GitHub Issue → 
Ручной запуск пайплайна → Полный релиз → ArgoCD деплой
```

## 📈 Мониторинг

- **GitHub Actions** - статус пайплайнов
- **Docker Hub** - образы
- **ArgoCD** - статус деплоя в Kubernetes
- **GitHub Issues** - уведомления о новых версиях
