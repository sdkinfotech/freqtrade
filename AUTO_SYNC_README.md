# Автоматическая синхронизация с upstream

Этот набор скриптов обеспечивает автоматическую ежедневную синхронизацию вашего форка freqtrade с upstream репозиторием без запуска CI/CD пайплайнов.

## 🎯 Решения

### 1. GitHub Actions (Рекомендуется для GitHub форков)

**Файл:** `.github/workflows/auto-sync.yml`

**Как работает:**
- Запускается каждый день в 3:00 UTC (6:00 MSK)
- Автоматически проверяет наличие новых коммитов в upstream
- Временно отключает пайплайны во время синхронизации
- Синхронизирует с upstream/develop
- Включает пайплайны обратно
- Отправляет изменения в ваш форк

**Настройка:**
1. Скопируйте файл `.github/workflows/auto-sync.yml` в ваш форк
2. Настройте права доступа в настройках репозитория
3. Готово! Синхронизация будет происходить автоматически

**Плюсы:**
- Полностью автоматическая
- Работает в облаке GitHub
- Не требует локального сервера
- Логи доступны в интерфейсе GitHub

### 2. Локальный cron (Для локальных репозиториев)

**Файлы:** `auto-sync-daily.sh`, `setup-auto-sync.sh`

**Как работает:**
- Скрипт `auto-sync-daily.sh` выполняет синхронизацию
- Cron запускает скрипт каждый день в 3:00
- Логи сохраняются в `/var/log/freqtrade-sync.log`
- Поддерживает email уведомления

**Настройка:**
```bash
# Автоматическая настройка
./setup-auto-sync.sh

# Или ручная настройка cron
crontab -e
# Добавить строку:
# 0 3 * * * /home/antsdk/pro/algotrading/freqtrade/auto-sync-daily.sh >> /var/log/freqtrade-sync.log 2>&1
```

**Плюсы:**
- Работает с любыми репозиториями
- Полный контроль над процессом
- Поддержка email уведомлений
- Работает офлайн

## ⚙️ Настройки

### Изменение времени синхронизации

**GitHub Actions:**
```yaml
# В файле .github/workflows/auto-sync.yml
schedule:
  - cron: '0 3 * * *'  # Измените время здесь
```

**Cron:**
```bash
# Редактировать cron задачи
crontab -e

# Примеры времени:
# 0 3 * * *    # Каждый день в 3:00
# 0 */6 * * *  # Каждые 6 часов
# 0 3 * * 1    # Каждый понедельник в 3:00
```

### Email уведомления (только для локального cron)

В файле `auto-sync-daily.sh`:
```bash
EMAIL_NOTIFICATIONS="true"
EMAIL_ADDRESS="your-email@example.com"
```

### Изменение ветки синхронизации

По умолчанию синхронизация происходит с `upstream/develop`. Для изменения:

**GitHub Actions:**
```yaml
# Замените upstream/develop на нужную ветку
git merge upstream/stable --no-edit
```

**Локальный скрипт:**
```bash
# В файле auto-sync-daily.sh замените:
git merge upstream/develop --no-edit
# На:
git merge upstream/stable --no-edit
```

## 🚨 Устранение проблем

### Синхронизация не работает

1. **Проверьте права доступа:**
   ```bash
   # Для GitHub Actions - настройки репозитория
   # Для cron - права на файлы
   ls -la auto-sync-daily.sh
   ```

2. **Проверьте логи:**
   ```bash
   # GitHub Actions - в интерфейсе GitHub
   # Локальный cron
   tail -50 /var/log/freqtrade-sync.log
   ```

3. **Проверьте upstream remote:**
   ```bash
   git remote -v
   # Должен быть upstream https://github.com/freqtrade/freqtrade.git
   ```

### Конфликты при синхронизации

Если возникают конфликты:
1. Разрешите конфликты вручную
2. Зафиксируйте изменения
3. Следующая автоматическая синхронизация должна пройти успешно

### Отключение автоматической синхронизации

**GitHub Actions:**
- Удалите файл `.github/workflows/auto-sync.yml`
- Или отключите workflow в настройках репозитория

**Локальный cron:**
```bash
crontab -e
# Удалите строку с auto-sync-daily.sh
```

## 🔧 Дополнительные возможности

### Синхронизация нескольких веток

Можно настроить синхронизацию нескольких веток одновременно, модифицировав скрипты:

```bash
# В auto-sync-daily.sh добавить:
git checkout stable
git merge upstream/stable --no-edit
git push origin stable
```

### Уведомления в Telegram/Discord

Можно добавить webhook уведомления, модифицировав скрипты для отправки сообщений в мессенджеры.
